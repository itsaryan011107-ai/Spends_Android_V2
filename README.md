# Spends_Android_V2

Standalone Android project for the Spends app.

## Included

- Android application source and resources
- Gradle wrapper and project configuration
- Capacitor Android module required for a self-contained build
- Capacitor Cordova Android plugin sources
- Latest debug APK at `releases/spends-android-v2-debug.apk`

## Build

1. Install Android Studio and an Android SDK with API 37.
2. Set `ANDROID_HOME` or `ANDROID_SDK_ROOT` to your Android SDK directory.
3. Run `gradlew.bat assembleDebug` on Windows.
4. The generated APK will be under `app/build/outputs/apk/debug/`.

The checked-in APK was generated from the latest local Android build on September 14, 2026.
